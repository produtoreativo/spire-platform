# SLO Standards

## SLO Definition

Each SLO should include:

- Service or platform capability.
- User journey or platform outcome protected.
- SLI query or measurement source.
- Target and measurement window.
- Error budget policy.
- Alerting approach.
- Owner and escalation path.
- Decision Trail reference.

## Recommended SLI Categories

- Availability.
- Request latency.
- Error rate.
- Freshness or processing delay.
- Deployment success.
- Platform reconciliation health.
- Incident response readiness.

## Review Cadence

- Review SLOs during Continuous Assessment.
- Review error budget burn during release planning.
- Review missed SLOs during incident analysis.
- Update scorecards and reliability plans when SLO evidence changes.
